# 🚀 AutoBiz IA — Micro-Service B2B Automatisé

## 1. Vision & Objectifs
* **Modèle** : Micro-Service B2B "Productized" (Rapports / Audits automatisés à haute valeur perçue).
* **Objectif financier Phase 1** : Atteindre **1 000 € de chiffre d'affaires**, réinvestis à 100% dans la croissance et l'infrastructure.
* **Budget initial alloué** : **50 €** max.
* **Temps opérateur visé** : < 30 minutes / semaine (supervision des paiements et alertes).
* **Niveau technique requis pour l'opérateur** : 0 (système autonome piloté par IA).

## 2. Règle du Hub & Rôle du Directeur (Discussion Manager)
* **RÈGLE FONDAMENTALE D'OR : ZÉRO OPÉRATIONNEL DANS CETTE DISCUSSION**
  * Cette discussion est le **Directeur Général**.
  * Le Directeur **gère, arbitre, coordonne et délègue aux sous-discussions**, mais **ne produit JAMAIS d'opérationnel directement** (pas d'exécution de scripts de génération, pas de création directe de factures ou de rapports dans cette discussion).
  * Chaque tâche opérationnelle DOIT obligatoirement être envoyée et exécutée dans sa sous-discussion respective via les agents dédiés.
* **Règle Stricte d'Isolation** : Dès qu'un nouveau sujet ou besoin métier émerge (ex: support client, comptabilité, nouvelle offre, etc.), le Manager alerte immédiatement l'utilisateur pour qu'une **nouvelle discussion dédiée** soit créée dans l'interface, avec son propre sous-dossier et son brief.
* **Sous-espaces / Modules Actuels** :
  * `01_niche_et_offre` : Définition de la cible B2B, proposition de valeur et pricing.
  * `02_prospection_auto` : Scraping, sourcing de prospects et enrichissement sans coût.
  * `03_moteur_audit_ia` : Agent IA d'analyse, génération des rapports PDF/Notion.
  * `04_distribution_ventes` : Séquençage email, page de paiement Stripe, livraison automatisée.
  * `05_deploiement_et_lancement` : Configuration cloud 24/7 et batchs de prospects qualifiés.
  * `06_commercial_et_emails` : Agent commercial dédié, envoi via plugin Gmail (`vumavuma148@gmail.com`) et suivi des réponses prospects.
  * `07_comptabilite_et_tresorerie` : Facturation légale conforme, livre des recettes URSSAF et jauge vers les 1 000 €.
  * `08_page_systeme_auto` : Page vitrine interactive, explicative et démonstrateur visuel du système autonome.
  * `07_comptabilite_et_tresorerie` : Agent RAF / Facturation légale PDF automatique pour chaque vente Stripe (49 €) et tableau de bord financier de suivi des 1 000 € de CA à réinvestir.
